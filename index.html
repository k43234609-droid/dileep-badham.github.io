Analyzes submitted source code and returns structured, actionable improvement suggestions by orchestrating a Python backend with the GPT-4 API — automating the first pass of a code review.

Key Features
  • Accepts source files and parses them into review-ready chunks
  • Constructs prompts that frame the code for consistent, targeted feedback
